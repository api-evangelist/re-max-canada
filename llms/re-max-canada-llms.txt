# RE/MAX Canada

> RE/MAX Canada is the Canadian arm of RE/MAX, LLC — a brokerage franchisor and bilingual consumer portal operator (remax.ca), not a data owner. It publishes **no developer portal, no API programme, no OpenAPI/Swagger/GraphQL/AsyncAPI document and no OData $metadata**, and holds **no RESO certification of any kind**. Canadian residential listing content is cooperatively controlled by CREA and the member boards through REALTOR.ca and the Data Distribution Facility, so remax.ca displays MLS content it licenses rather than publishes. The only anonymously callable machine-readable surface in the entire estate is the stock WordPress REST API on its marketing blog — content, not property data.

## What an agent can actually call

- [WordPress REST discovery index](https://blog.remax.ca/wp-json/): HTTP 200, 446,832 bytes, 25 namespaces, 563 self-describing routes. The only machine-readable contract RE/MAX Canada serves. Harvested verbatim to `openapi/re-max-canada-blog-wp-json-index.json`.
- [Blog posts](https://blog.remax.ca/wp-json/wp/v2/posts): anonymous read, HTTP 200. Canadian real estate news. `per_page` is capped at 10; paginate with `page` and read `X-WP-Total` / `X-WP-TotalPages`.
- [Authors](https://blog.remax.ca/wp-json/wp/v2/users): anonymous read, HTTP 200.
- [RSS feed](https://blog.remax.ca/feed/): HTTP 200, application/rss+xml.
- The identical stock WordPress REST API is also live and open on [join.remax.ca](https://join.remax.ca/wp-json/), [franchise.remax.ca](https://franchise.remax.ca/wp-json/) and [agentbrokerhub.remax.ca](https://agentbrokerhub.remax.ca/wp-json/).

## What does not exist — do not look for it

- No listings, property, agent, office, valuation, transaction or rental API. remax.ca renders those as web pages only.
- No developer portal. `developer.remax.ca`, `developers.remax.ca` and `docs.remax.ca` answer HTTP 403 but are **DNS wildcard artifacts** — the control probe `zzzznotreal.remax.ca` resolves to the same target (CNAME `customers.kvcore.com`). They are not portals.
- No API at `api.remax.ca`. It is a real AWS load balancer that 301-redirects every path to www.remax.ca.
- No RESO Web API, Data Dictionary certification, `$metadata` or Universal Property Identifier.
- No SDKs, CLI, Postman collection, sandbox, changelog, roadmap, pricing, rate-limit documentation or status page (`status.remax.ca` is a **dangling** Pingdom CNAME returning "404 - Status Page not Found").
- No `/.well-known/` documents: no security.txt, no OpenID configuration, no OAuth authorization-server metadata, no api-catalog, no ai-plugin.json.
- No webhooks, events or AsyncAPI.

## Access, licensing and agent etiquette

- **The two halves of this estate have opposite postures.** `blog.remax.ca/robots.txt` explicitly ALLOWS GPTBot, OAI-SearchBot, ChatGPT-User, ClaudeBot, Claude-SearchBot, Claude-User, PerplexityBot, Perplexity-User, Google-Extended, CCBot and cohere-ai. The `www.remax.ca` [terms of use](https://www.remax.ca/terms-of-use) forbid automated, electronic or high-volume means — including crawlers, scripts and other automated devices — from accessing the services, and `www.remax.ca/robots.txt` disallows `/api/`, `/v2/`, `/feature-flags/`, `/qc` and `/quebec`. **Agents may read the blog; agents must not scrape the listings portal.**
- Home price estimates on remax.ca are supplied by Teranet Inc. under a **personal-use-only** licence that forbids commercial use, resale, external distribution and sublicensing — even though Teranet's inputs derive in part from public records collected by the Province of Ontario, the Province of Manitoba and the British Columbia Assessment Authority.
- A developer who needs Canadian MLS listing data must go one layer up, to CREA's Data Distribution Facility (DDF®) — which requires a REALTOR® membership relationship and a signed data licence — or to a member board / board technology provider such as ITSO or Pillar 9. RE/MAX Canada neither controls nor resells any of it.

## Authentication

- Anonymous read on the `wp/v2` content namespace. No key, no token, no signup.
- Everything else requires WordPress **Application Passwords** (HTTP Basic over TLS), authorized at https://blog.remax.ca/wp-admin/authorize-application.php — a CMS staff login, not developer onboarding. Failed anonymous calls return `{"code":"rest_forbidden","message":"Sorry, you are not allowed to do that.","data":{"status":401}}`.
- No OAuth 2.0, no OpenID Connect, no API keys, no mTLS, no scopes.
